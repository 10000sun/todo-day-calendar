# 투두캘린더
달력 + 일별 투두 + D-day 안드로이드 앱 (Kotlin / Compose / Room / Glance).

- 달력에서 날짜 선택 → `＋`로 할 일/일정 추가, 항목을 누르면 수정
- 반복(매일/매주/매월/매년), 시간 지정, 정시 알림, D-day (생일 같은 매년 반복 D-day 포함)
- 홈 화면 위젯 2종: 오늘 할 일 위젯 / 월간 달력 위젯
- 잠금화면: 오늘 할 일을 고정 알림으로 표시 (설정 > 잠금화면 > 알림 내용 모두 표시)
- 빌드: Android Studio에서 열기 또는 `./gradlew :app:assembleDebug` (CI 아티팩트에 APK 포함)
